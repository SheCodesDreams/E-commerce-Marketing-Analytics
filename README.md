# E-Commerce Marketing Analytics

## 📌 Project Overview

An end-to-end data analytics project focused on understanding e-commerce customer behavior, marketing performance, customer segmentation, and campaign efficiency.

The project uses Python, Pandas, SQL, and Power BI to transform raw customer, session, transaction, campaign, and geographic data into actionable business insights.

The analysis focuses on customer acquisition, revenue performance, purchasing behavior, retention opportunities, and marketing efficiency.

---

## 🎯 Business Objectives

- Evaluate customer acquisition performance across marketing channels
- Analyze campaign and campaign-type performance
- Understand customer purchasing and retention behavior
- Identify high-value and at-risk customer segments
- Analyze revenue and acquisition trends over time
- Evaluate campaign efficiency using CAC and ROAS
- Build an interactive Power BI dashboard for executive-level reporting
